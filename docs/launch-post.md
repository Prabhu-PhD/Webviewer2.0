## Microsoft Tech Community / PowerPoint forum

**Title:** Free replacement for the retired Web Viewer add-in

**Body:**

Microsoft retired the Web Viewer add-in on December 2, 2024, and I've been building a replacement ever since. It's called **Webviewer 2.0** and it's free.

**What it does:**

Paste a URL into the add-in bar and it appears as a live embedded frame directly on your slide — no alt-tabbing, no separate window. YouTube, Vimeo, Loom, Google Slides, Google Docs, Google Forms, Power BI dashboards, countdown timers, live data feeds — if the site allows embedding, it works.

**Features beyond the original Web Viewer:**

- Paste up to 4 URLs separated by commas for a side-by-side split-screen view
- Auto-refresh on a 30 s / 1 m / 5 m timer so dashboards stay current during a presentation
- Draw mode — annotate over the live content with a stylus or mouse
- Mobile view — scales the embed to 390 px width so you can preview mobile layouts
- QR code button — instantly generate a scannable code for the current URL
- Zoom controls
- Dark toolbar option
- Presentation Lock — disables accidental clicks during slideshow mode

**Install:**

Search "Webviewer 2.0" in PowerPoint → Insert → Get Add-ins, or sideload the manifest from GitHub.

GitHub: https://github.com/Prabhu-PhD/Webviewer2.0

Happy to answer questions here or via GitHub issues.

## Product Hunt

**Tagline:** Free PowerPoint add-in that embeds live web content directly on your slides

**Description:**

Microsoft retired its Web Viewer add-in in December 2024, leaving educators, trainers, and presenters without a way to embed live web content inside PowerPoint slides.

Webviewer 2.0 is the free, open-source replacement — with features the original never had.

**What you can do:**
- Paste any URL and it appears as a live frame on your slide
- Split-screen: separate up to 4 URLs with commas
- Auto-refresh: keep dashboards live during a presentation (30 s / 1 m / 5 m)
- Draw over the embedded content with a stylus or mouse
- Mobile view: preview any site at 390 px phone width
- QR code: generate a scannable link for the current URL in one click
- Zoom, dark toolbar, Presentation Lock

Providers like YouTube, Vimeo, Loom, Google Slides, Google Docs, Google Forms, and Vimeo are auto-converted to their embed URLs so you don't need to find the special embed link.

Free. No account. No data collected.
